# 운행일지 무효처리(VOID) 기능 — 작업완료보고서

---

## 1. 개요

운행일지(Trip Log)는 한국 업무용승용차 운행기록부 / 베트남 세무 보고에 사용되는 법적·감사 데이터이다. 잘못 입력된 건을 안전하게 처리하기 위해 **하드 삭제 대신 `VOIDED` 상태로 무효 처리하는 기능**을 추가했다. 모든 무효 처리는 사유·처리자·시간을 영구 기록하며, VOIDED 는 종료 상태로 되돌릴 수 없다 (필요 시 DB 직접 조작 — 감사 흔적 유지 목적).

### 2.3 신규 에러 코드

| 코드 | 메시지 | 상황 |
|------|--------|------|
| `CAR-E6005` | Cannot void verified trip log | VERIFIED 상태에서 void 시도 |
| `CAR-E6006` | Trip log already voided | VOIDED 상태 재 void (멱등성) |

기존 `CAR-E6002` 메시지를 "Cannot update verified trip log" → 상황에 따라 "Cannot update voided trip log" / "Cannot submit voided trip log" 등 분기 메시지 추가.

ALTER TABLE car_trip_logs
  MODIFY COLUMN ctl_status ENUM('IN_PROGRESS','COMPLETED','VERIFIED','VOIDED')
    NOT NULL DEFAULT 'IN_PROGRESS';

ALTER TABLE car_trip_logs
  ADD COLUMN ctl_voided_at DATETIME NULL AFTER ctl_status,
  ADD COLUMN ctl_voided_by CHAR(36) NULL AFTER ctl_voided_at,
  ADD COLUMN ctl_voided_by_name VARCHAR(100) NULL AFTER ctl_voided_by,
  ADD COLUMN ctl_voided_reason VARCHAR(500) NULL AFTER ctl_voided_by_name;
SQL

## 5. 사용자 안내 (UX 변경 사항)

| 변경 | 사용자 영향 |
|------|----------|
| 잘못 입력된 운행일지에 대한 "무효 처리" 버튼이 상세 페이지에 추가됨 | ✅ 새 기능 — 즉시 사용 가능 |
| 무효 처리된 일지는 목록에서 회색·취소선으로 표시됨 | ✅ 시각적 구분으로 한눈에 식별 |
| 월간 통계(총 운행수·총 거리·총 연료비)는 VOIDED 를 **제외**하여 계산됨 | ⚠️ 통계 값 변경 가능 — 기존에 잘못 합산되던 값이 정확해짐. 사용자에게 안내 필요. |
| Excel Export 에 "무효처리일", "무효사유" 컬럼이 끝에 추가됨 | ℹ️ 기존 사용자 매크로/스프레드시트 영향 없음 (컬럼 순서 변경 없음) |
| VOIDED 상태에서는 수정/제출/검증/재무효 불가 | ⚠️ 의도된 동작. 무효는 되돌릴 수 없으므로 사유 입력 시 주의 |

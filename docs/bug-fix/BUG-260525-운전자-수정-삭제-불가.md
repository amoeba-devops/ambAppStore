## 3. 수정 방안

### 3.1 DriverListPage 액션 컬럼 추가

[DriverListPage.tsx](apps/app-car-manager/frontend/src/pages/DriverListPage.tsx) 테이블에 액션 컬럼 추가:

```tsx
<th>{t('common.actions')}</th>

// 각 행:
<td className="px-3.5 py-3 text-right">
  <button onClick={() => setEditingDriver(d)} className="...">
    <Pencil className="h-4 w-4" />
  </button>
  <button onClick={() => handleDelete(d)} className="...">
    <Trash2 className="h-4 w-4" />
  </button>
</td>
```

상태 추가: `const [editingDriver, setEditingDriver] = useState<Driver | null>(null);`

삭제 핸들러:
```tsx
const deleteMut = useDeleteDriver();
const handleDelete = async (d: Driver) => {
  if (!confirm(t('driver.confirmDelete', { name: d.driverName }))) return;
  try {
    await deleteMut.mutateAsync(d.driverId);
    addToast({ type: 'success', message: t('driver.deleted') });
  } catch (e) {
    addToast({ type: 'error', message: String((e as Error).message) });
  }
};
```

### 3.2 DriverFormModal 편집 모드 지원

Props 확장:
```typescript
interface DriverFormModalProps {
  open: boolean;
  onClose: () => void;
  vehicleId?: string;
  driver?: DriverResponse;  // ← 신규: 있으면 편집 모드
}
```

- `driver`가 있으면 `useUpdateDriver()` 사용, 폼 초기값 driver에서 prefill (`role`, `note`).
- AMA 사용자 선택 영역은 편집 모드에서 **disabled** (변경 불가, 표시만).
- Submit 핸들러:
  ```typescript
  if (driver) {
    await updateMut.mutateAsync({ id: driver.driverId, data: { role, note } });
  } else {
    await createMut.mutateAsync({ ... });
  }
  ```
- 타이틀: `driver ? t('driverForm.editTitle') : t('driverForm.title')`

### 3.3 상태 변경 + 차량 배정 (선택 — Phase 2)

편집 모달 안에 다음도 추가 가능 (별 모달로 분리해도 무방):
- 상태 드롭다운(ACTIVE/ON_LEAVE/INACTIVE) → `useUpdateDriverStatus`
- 차량 배정/해제 → `useAssignDriver` / `useUnassignDriver`

MVP 수정에서는 **편집(역할/노트) + 삭제만** 우선 구현하고 상태/배정은 차후 작업으로 분리 권장.

> # 또는: export JWT='-H "Authorization: Bearer eyJ..."'

### 단계 6 — 컨펌 (S08)

매칭 결과의 candidates 배열을 그대로 컨펌 요청에 첨부:

```bash
SELECTED_HS=$(echo $MATCH_RES | jq -r '.data.candidates[0].hsCode')
CANDIDATES_JSON=$(echo $MATCH_RES | jq -c '
  .data.candidates | map({
    hs_code: .hsCode,
    description: .description,
    basic_tariff_rate: .basicTariffRate,
    fta_tariff_rate: .ftaTariffRate,
    fta_agreement_code: .ftaAgreementCode,
    source: .source,
    ranking: .ranking,
    confidence: .confidence,
    reasoning: .reasoning,
    source_citations: .sourceCitations,
    external_adapter_keys: .externalAdapterKeys,
    flags: .flags,
    past_adoption_count: .pastAdoptionCount
  })
')

CLS_RES=$(curl -s -X POST http://localhost:3102/api/v1/classifications \
  -H "Content-Type: application/json" $H_AUTH \
  -d "{
    \"inquiry_id\": \"$INQ_ID\",
    \"item_id\": \"$ITEM_ID\",
    \"selected_hs_code\": \"$SELECTED_HS\",
    \"candidates\": $CANDIDATES_JSON

echo $CLS_RES | jq '{classification: .data.classification | {id, hsCode, status, ftaAgreementCode}, supersededId: .data.supersededId}'
```

## 6. 부하 테스트 (옵션, NFR-PF-01·02)

```bash
# k6 설치 (macOS): brew install k6

cat > k6-matching.js <<'EOF'
import http from 'k6/http';
import { sleep, check } from 'k6';
export const options = { vus: 50, duration: '5m' };

export default function () {
  const res = http.post(
    'http://localhost:3102/api/v1/matching/run',
    JSON.stringify({ inquiry_id: __ENV.INQ_ID, item_id: __ENV.ITEM_ID }),
    { headers: {
        'Content-Type': 'application/json',
        'X-Entity-Id': 'ent-test-001',
        'X-Entity-Code': 'TEST',
        'X-Entity-Email': 'test@local',
      }
    }
  );
  check(res, {
    '200': r => r.status === 200,
    '90p < 8s (NFR-PF-02)': r => r.timings.duration < 8000,
  });
  sleep(0.5);
}
EOF

INQ_ID=$INQ_ID ITEM_ID=$ITEM_ID k6 run k6-matching.js
```

**기대**: 90p < 8s, 실패율 < 1%

## 7. 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| `401 HSC-E0101` | JWT 누락 또는 `ALLOW_ENTITY_HEADER_AUTH` 미설정 | `.env` 에 `ALLOW_ENTITY_HEADER_AUTH=true` 추가 후 BE 재시작 |
| `400 HSC-E0301` | Inquiry 생성 시 NOT_SUPPORTED 수입국 | 단계 2에서 `import_country_code: "VN"` 확인 |
| `400 HSC-E0320` | 완성도 점수 < 0.7 | `attachment_count: 2` 추가 또는 모든 필수 필드 채우기 |
| `409 HSC-E0420` | 중복 컨펌 — 같은 (exporter, import, hash, date) 존재 | `overwrite_existing: true` 로 재호출 또는 `submitted_at` 변경 |
| AI mock 모드 | `CLAUDE_API_KEY` 미설정 | 정상 — `metadata.aiStatus: "MOCK"` 확인 |
| 외부 어댑터 빈 결과 | BIEU THUE 시드 부족 | `SEED_DEMO_DATA=true` 로 50건 확장 시드 적용 |

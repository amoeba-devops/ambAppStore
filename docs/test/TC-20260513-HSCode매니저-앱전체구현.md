# HS Code Manager — Test Cases (테스트케이스)

> 본 TC 문서는 [PLAN-20260513-HSCode매니저-앱전체구현.md](../plan/PLAN-20260513-HSCode매니저-앱전체구현.md)의 8개 Phase별 구현 산출물을 검증한다. 테스트는 *Phase별로 게이트 통과 가능 여부*를 결정한다 — 한 Phase의 모든 P0(Must) TC가 통과해야 다음 Phase로 진입한다.

## 1. 문서 개요

### 1.1 테스트 범위

| Phase | 범위 |
|-------|------|
| 0 | 골격, 헬스체크, AMA JWT 검증, 빈 DB 마이그레이션, S01 렌더링 |
| 1 | 마스터(수입국/수출국/Exporter/FTA/외부소스), 사용자·권한, EntityScopeGuard |
| 2 | Inquiry/Item, 입력 채널 3종, 엑셀 헤더 매핑·보류 큐, 완성도 점수 |
| 3 | 정규화·해시, 내부 매칭, 외부 어댑터(VN/KR), AI 추천, 랭킹 |
| 4 | Classification 컨펌·영속화, 중복 감지, supersede, 감사 로그, 응대 양식, 누적 조회 |
| 5 | VerificationEvent, 자동 supersede, 재검토 큐, KPI 1차 집계 |
| 6 | 에스컬레이션 6개 트리거, 라우팅, 차단 동작 |
| 7 | 정책 임계값, KPI 대시보드, 운영 지표 |
| 8 | 어댑터 SDK, 신규 국가 등록 절차 |
| NFR | 성능, 가용성, 보안(멀티테넌시), 데이터 정합성, 다국어 |

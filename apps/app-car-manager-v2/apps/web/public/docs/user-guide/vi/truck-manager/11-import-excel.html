Import Excel

Mở trang trong app /truck/import →

URL
/truck/import
Mục đích
Nhập hàng loạt nhật ký chuyến từ file Excel — dùng khi đã có sẵn dữ liệu chạy xe ở nơi khác

Các bước sử dụng

  1. Bấm Tải file mẫu để lấy đúng cấu trúc cột.
  2. Chọn Xe và Tài xế áp dụng cho toàn bộ file (một file chỉ gán cho một xe + một tài xế).
  3. Kéo-thả hoặc bấm để chọn file .xlsx/.xls đã điền.
  4. Nếu file có nhiều sheet: chọn sheet cần nhập ở hàng chọn sheet — mỗi sheet coi là một tháng.
  5. Kiểm tra ánh xạ cột: hệ thống tự đoán theo tên cột, có thể đổi lại thủ công. Cột Ngày là bắt buộc.
  6. Xem bảng xem trước: số dòng hợp lệ (xanh) và lỗi (đỏ, thường do thiếu ngày).
  7. Bấm Nhập N dòng — chỉ dòng hợp lệ được nhập.

Logic / Quy tắc

  • File mẫu CR-Vietnam-Truck-v1 có 17 cột (gồm cả cột Xe (biển số) — chỉ để tham khảo, vì xe/tài xế đã chọn riêng ở trên). Ứng dụng đọc 16 cột còn lại: ngày, giờ đi/về, khách hàng, điểm lấy/giao hàng, km đầu/cuối, lượng nhiên liệu + đơn giá, phí cầu đường, chi phí khác + ghi chú, số BOL, số CDF, doanh thu.
  • Sau khi nhập thành công, hệ thống chuyển thẳng tới Nhật ký chuyến lọc theo tháng vừa nhập để kiểm tra ngay.
  • Nhập được cả vào tháng/khu vực đã lập báo cáo (không khoá dữ liệu) — nhớ lập lại báo cáo sau khi nhập để cập nhật số chính thức.

3 chế độ xem calendar

  • Theo xe — gom row theo biển số (dễ thấy xe nào quá tải)
  • Theo trạng thái — gom theo PENDING / CONFIRMED / IN_PROGRESS / COMPLETED
  • Theo thời gian — Tháng / Tuần / Ngày / Tùy chỉnh

Hành động trên dashboard

  • + Tạo chuyến mới — góc trên phải, mở form Quản lý chuyến đi
  • Bấm vào card chuyến trong calendar → mở chi tiết
  • Bấm vào card xe trong panel "Phương tiện" → mở trang xe

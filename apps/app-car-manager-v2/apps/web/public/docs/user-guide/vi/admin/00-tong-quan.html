Quản trị viên — Tổng quan

Đối tượng
Admin doanh nghiệp — mapped từ AMA OWNER hoặc MASTER
Thiết bị
Web (máy tính) — các thao tác CRUD phức tạp
Quyền
Toàn quyền — không có thao tác nào bị giới hạn

Là Quản trị viên, bạn vận hành toàn bộ hệ thống. Ngoài các tính năng của Quản lý/Tài xế, bạn có thêm 4 nhóm trang độc quyền: Người dùng, Cảnh báo bảo dưỡng, Cấu hình, Audit log.

11 nhóm chức năng

NhómMục đích
DashboardTổng quan toàn đội xe — lịch + KPI
Quản lý xeĐăng ký, sửa, theo dõi xe — chu kỳ thay dầu, đăng kiểm
Quản lý tài xếHồ sơ tài xế + bằng lái + thời hạn
Người dùngMời thành viên + đổi vai trò trong app
Chuyến điTạo + gán driver/vehicle + hủy chuyến
Quản lý chi phíSổ chi phí toàn công ty + xuất CSV
Cảnh báo bảo dưỡngTheo dõi + giải quyết alert dầu / đăng kiểm
Báo cáoKPI tổng, donut chart loại chi phí, line chart utilization
Cấu hìnhTên tổ chức, ngôn ngữ mặc định, retention, push
Audit logNhật ký mọi thao tác, lưu 5 năm, không sửa được

Bạn KHÔNG cần lo

  • Tạo tài khoản user — AMA quản lý; bạn chỉ "mời" user đã có tài khoản AMA và cấp quyền dùng app
  • Backup database — Neon Postgres tự backup hàng giờ
  • Xoá log audit — không có chức năng xoá, chỉ insert
  • Triển khai — tự động deploy qua git push
⚠️

Trách nhiệm: Là Admin, mọi thao tác của bạn đều được ghi audit log với tên + timestamp + IP. Hãy thận trọng khi đổi vai trò user hoặc thay đổi cấu hình hệ thống.

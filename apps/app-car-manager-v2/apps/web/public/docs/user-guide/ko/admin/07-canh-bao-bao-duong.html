정비 알림 (Maintenance Alerts)

앱에서 이 페이지 열기 /vehicles →

트리거
매일 06:00 ICT 자동 크론 실행 — 전체 차량 스캔
표시 위치
알림함 /inbox + /vehicles 차량 카드 상단 배너
처리 책임
관리자 (일정 조율 + 완료 후 OIL/INSPECTION 비용 등록)

4가지 알림 유형

코드발생 조건심각도
OIL_DUE_SOON차량 주행거리가 엔진오일 교환 주기의 80% 이상 도달 (기본값 4,000 km / 2.4개월)WARNING
OIL_OVERDUE차량이 엔진오일 교환 주기를 초과함CRITICAL
INSPECTION_DUE_SOON정기검사 만료까지 30일 이하 남음WARNING
INSPECTION_OVERDUE정기검사 기한이 이미 지남CRITICAL

처리 절차

1

/inbox 또는 /vehicles를 열어 알림이 있는 차량을 확인합니다 (차량 카드의 ⚠ 아이콘).

2

해당 차량 담당 기사에게 연락 → 정비소/정기검사 센터 방문 일정을 조율합니다.

3

/vehicles/[id]/edit에서 차량 상태를 MAINTENANCE로 변경하여 신규 운행 배정을 차단합니다.

4

정비 완료 후 /expenses/new에서 OIL 또는 INSPECTION 유형으로 비용을 등록합니다 — 해당 차량을 정확히 선택하세요.

5

시스템이 자동으로 처리합니다:

  • 정비 주기 초기화 (km/일 카운트를 0부터 재시작)
  • 알림함의 해당 알림을 RESOLVED로 표시
  • 다음 주기까지 크론이 동일 알림을 재발송하지 않음
6

차량 상태를 AVAILABLE로 변경하여 기사/매니저가 다시 운행을 신청할 수 있게 합니다.

정비 주기 설정

각 차량별로 /vehicles/[id]/edit에서 개별 설정할 수 있습니다:

  • 오일 교환 주기 (km) — 기본값 5,000 km
  • 오일 교환 주기 (개월) — 기본값 3개월
  • 정기검사 주기 (개월) — 기본값 12개월 (차령 7년 이하) / 6개월 (차령 7년 초과)
⏰

중복 방지 (Idempotency window): 24시간 내 동일 알림 재발송 없음. 크론이 하루에 여러 번 실행되어도 동일 알림이 중복 발송되지 않습니다.

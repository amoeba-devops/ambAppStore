Amoeba Car Manager v2는 Amoeba App Store 플랫폼 위에서 운영되는 기업 내부 차량 배차 및 비용 관리 시스템입니다. 세 가지 핵심 업무 흐름을 지원합니다: 차량 배차, 비용 추적, 자동 정비 알림.

3가지 사용자 역할

역할특징주 사용 기기
관리자시스템 전권 — 설정, 비용 검토, 차량 배정, 보고서 조회, 감사 로그 확인웹 브라우저
매니저 / 디렉터본인 또는 팀의 차량 예약, 이력 추적, 본인 운행 취소웹 + 모바일
기사운행 일정 확인, 운행 상태 업데이트, 발생 비용 기록모바일 (PWA)

9가지 기능 그룹

시스템은 9개의 기능 모듈로 구성되어 있습니다. 각 모듈은 다음 페이지에서 역할별로 자세히 안내합니다.

  1. 차량 관리 — 차량 등록, 엔진오일 교환 주기, 정기검사
  2. 기사 관리 — 기사 목록, 운전면허, 만료일
  3. 사용자 관리 — 멤버 초대, 역할 변경
  4. 운행 — 예약, 배정, 추적, 취소 (7단계 상태 머신)
  5. 비용 — 8종 (주유, 엔진오일, 주차, 통행료, 식대, 수리, 사고, 정기검사)
  6. 정비 알림 — 주행거리 및 기간 기반 자동 알림
  7. 보고서 — Excel/PDF 다차원 내보내기
  8. 시스템 설정 — 승인 규칙, 조직 파라미터
  9. 감사 로그 — 수정 불가, 5년 보관

시스템 내 정보 흐름

운영 흐름 요약:

매니저 운행 예약  →  관리자 차량+기사 배정  →  기사 확인
                                                ↓
        보고서  ←  감사 로그  ←  기사 비용 기록 + 주행거리 마감
                                                ↓
                              시스템 자동 정비 알림 발송

이전 버전의 "계층적 승인" 기능 제거됨 (PRD revision 3) — Admin/매니저가 기준 금액 초과 비용을 승인하는 플로우가 있었습니다. PRD revision 3에서 승인 플로우가 제거되어, 모든 비용은 자동으로 기록됩니다. Admin은 검토 후 잘못된 경우에만 수정합니다.

전사 비용 장부

비용 장부 구성

  • 왼쪽 목록 — 조직의 모든 비용을 최신순으로 표시. 각 행: 유형 아이콘 + 차량 번호판, 금액, 출처 라벨(기사 / 백오피스 직원) + 이름 + 제출 시각.
  • 오른쪽 패널 (데스크톱) — 행을 클릭하면 읽기 전용 상세 표시: 금액, 유형, 연결된 운행, 차량, 기사, 메모, 영수증 이미지. 모바일에서는 행 클릭 시 별도 상세 페이지가 열립니다.

이 페이지에는 현재 화면 필터가 없습니다 — 모든 비용이 나열됩니다. 유형 / 날짜 / 차량별 분석이 필요하면 CSV 내보내기 후 Excel/Google Sheets에서 필터링하세요.

회계용 CSV 내보내기

  1. 오른쪽 상단 "CSV 내보내기" 클릭 — 전체 비용 장부 내보내기 (최신 최대 1000행)
  2. 다운로드 파일 열 구성: 비용 코드, 유형, 상태, 금액, 통화, 발생일, 제출 시각, 기사, 차량, 운행 코드, 메모
  3. Excel/Google Sheets로 열기 — UTF-8 인코딩 적용, 한글 표시 정상

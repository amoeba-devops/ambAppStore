이전 버전의 "계층적 승인" 기능 제거됨 (PRD revision 3) — Admin/매니저가 기준 금액 초과 비용을 승인하는 플로우가 있었습니다. PRD revision 3에서 승인 플로우가 제거되어, 모든 비용은 자동으로 기록됩니다. Admin은 검토 후 잘못된 경우에만 수정합니다.

전사 비용 장부

고급 필터

  • 유형별 — 8가지 유형 (FUEL, OIL, MEAL, REPAIR, ACCIDENT, PARKING, TOLL, INSPECTION)
  • 제출자별 — 기사 또는 매니저 선택
  • 차량별 — 번호판 선택
  • 운행별 — 특정 운행에 연결된 비용만 표시
  • 날짜 범위
  • 금액 범위 (최소/최대)
  • 메모 검색

다른 사용자 비용 수정

Admin은 모든 비용을 수정할 수 있습니다 — 사용자의 7일 잠금 이후라도 가능합니다:

  • 비용 항목 클릭 → 오른쪽 상세 패널 열림
  • "수정" 클릭 → 편집 폼 열림
  • 금액, 날짜, 유형, 메모 수정 → 저장
  • 감사 로그: EXPENSE.ADMIN_EDIT에 원래 사용자 + 수정자가 기록됨
⚠️

다른 사용자 비용 수정은 민감한 작업입니다. 수정 전 반드시 해당 사용자에게 알리고, 메모 필드에 수정 사유를 명확히 기입하세요.

회계용 CSV 내보내기

  1. 날짜 범위 필터 설정 (예: 2026년 5월)
  2. 오른쪽 상단 "CSV 내보내기" 클릭
  3. 다운로드 파일 열 구성: ID, 유형, 금액, 날짜, 제출자, 차량, 운행, 상태, 메모, 영수증 이미지 URL
  4. Excel/Google Sheets로 열기 — UTF-8 BOM 인코딩 적용, 한글 표시 정상

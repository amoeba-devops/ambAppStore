운행 등록(일지)

앱에서 열기 /truck/trips/new →

URL
/truck/trips/new
목적
새 화물 운행 일지 생성

사용 단계

  1. 고객 및 증빙 번호 BOL / CDF(있으면) 입력.
  2. 출발 → 도착 입력; 다구간이면 + 경유지 추가.
  3. 차량(운행 지역 결정)·기사 선택.
  4. 수치 입력: 연료(리터+단가)·통행료·매출 — 완료 시 기사가 입력하도록 비워둘 수 있음.
  5. 저장.

로직 / 규칙

  • 차량·기사는 나중에 배정 가능(생성 시 필수 아님).
  • 저장 시 수치 완비 전까지 완료 대기 상태.
  • 해당 월·지역이 마감되었으면 생성/수정 차단(정산 확정).

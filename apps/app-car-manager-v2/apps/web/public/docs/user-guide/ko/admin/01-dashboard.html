3가지 캘린더 보기 모드

  • 차량별 — 번호판 기준으로 행(row) 분류 (특정 차량의 과부하 여부 파악 용이)
  • 상태별 — PENDING / CONFIRMED / IN_PROGRESS / COMPLETED 기준으로 분류
  • 시간별 — 월 / 주 / 일 / 사용자 지정

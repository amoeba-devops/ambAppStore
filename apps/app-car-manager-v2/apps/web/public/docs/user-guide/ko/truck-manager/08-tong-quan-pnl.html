손익 개요

앱에서 열기 /truck/pnl →

URL
/truck/pnl
내용
지역·월별 손익 집계 + 주유 영수증

사용 단계

  1. 기간/지역을 선택해 최근 3개월 매출·비용·이익 집계 확인.
  2. 각 월 열 아래에 보고서 작성됨 · 시각 또는 미작성 배지 표시.
  3. 지역 필터로 HCM / 동나이 / Baiksan 효율 비교, 또는 차량별 필터.
  4. 특정 지역을 선택하면 아래에 주유 영수증 블록 표시: 4개 지표(평균 단가, 연비, 총 영수증 리터, 월 총 km)와 영수증 목록.
  5. 새 영수증 입력: 날짜·주유소·리터·단가 입력 후 추가.
  6. 필요 시 Excel 내보내기.

로직 / 규칙

  • 기간의 완료 운행 + 고정비에서 산출.
  • 평균 단가 = 해당 월·지역 주유 영수증 단가의 산술 평균; 연비 = 영수증 총 리터 ÷ 같은 지역 완료 운행 총 km.
  • 이 두 값은 보고서 작성이 운행별 연료비를 배분하는 입력값입니다 — 정확한 수치를 위해 보고서 작성 전에 영수증을 충분히 입력하세요.
  • 손익은 비용 & 손익 메뉴의 한 탭.

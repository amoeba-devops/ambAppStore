URL
/truck/reports/new
절차
3단계: 월 → 지역 → 확인

사용 단계

  1. 1단계 — 월 선택: 보고할 월 선택.
  2. 2단계 — 지역 선택: 한 지역(HCM/동나이/Baiksan) 또는 전체 지역.
  3. 3단계 — 확인 & 작성: 집계 수치 검토 후 생성.
  4. 생성된 보고서 Excel 다운로드(또는 보고서 목록에서).

로직 / 규칙(오류 차단)

  • 데이터 없는 월 → 2단계로 진행 불가, 1단계에서 즉시 경고.
  • 해당 월에 운행 없는 지역 → 3단계로 진행 불가, 2단계에서 즉시 경고.
  • 보고서는 지역명과 함께 명명되어 목록에 저장.

차량 신청 — 새 운행 만들기

URL
/trips/new
필수
출발지, 도착지, 출발 시각
선택
승객 (기본값 = 본인 계정), 기사, 차량, 목적, 경유지, 메모
자동 저장
5초마다 자동 저장 — 새로 고침해도 초안 유지

폼 열기

3가지 방법으로 폼을 열 수 있습니다:

  • 대시보드 우측 상단의 "+ 새 운행 만들기" 버튼 클릭
  • 사이드바 → 운행 → "+ 새로 만들기" 버튼 클릭
  • 직접 /trips/new로 이동

입력 항목

1

출발지 (필수) — 주소를 입력합니다. 예: 비텍스코 파이낸셜 타워, 호치민시 1군. Google Maps API가 설정된 경우 자동 추천이 제공됩니다.

2

도착지 (필수) — 출발지와 같은 방식으로 입력합니다.

3

출발 시각 (필수) — 날짜와 시간을 선택합니다. 기본값은 오늘 + 2시간 후입니다.

4

승객 (선택) — 기본값은 본인입니다. 대신 신청하는 경우 동료로 변경할 수 있습니다.

5

기사 + 차량 (선택) — 비워두면 관리자가 나중에 배정합니다. 여기서 바로 선택하면 일정이 겹칠 경우 시스템이 경고합니다.

6

목적 (선택이지만 강력 권장) — 간략하게 입력합니다. 예: Samsung Vietnam 파트너 미팅. 목적은 보고서와 감사 로그에 표시됩니다.

7

경유지 (선택, 최대 10개) — 중간에 들러야 하는 장소가 있는 경우 추가합니다. 각 경유지에 이름과 메모를 입력할 수 있습니다.

8

하단의 "운행 만들기" (파란색 버튼)를 클릭합니다. 운행이 성공적으로 생성되면 상세 페이지로 이동합니다.

운행 생성 후 상태

선택 여부즉시 전환되는 상태
기사를 선택하지 않은 경우배정 대기 — 관리자가 기사/차량을 배정해야 함
기사 + 차량을 선택한 경우기사 확인 대기 — 기사에게 알림 발송
💡

팁: 미리 신청하세요 — 특히 급한 경우에는 더욱 중요합니다. 시스템이 별도로 승인하지는 않지만, 기사는 확인하고 차량을 준비하는 데 시간이 필요합니다.

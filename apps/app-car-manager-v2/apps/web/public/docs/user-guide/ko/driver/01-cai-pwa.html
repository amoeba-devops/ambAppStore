PWA (Progressive Web App)를 이용하면 Amoeba Car Manager를 네이티브 앱처럼 스마트폰에 설치할 수 있습니다. 홈 화면에 전용 아이콘이 생기고, 전체 화면으로 실행되며, 푸시 알림도 수신할 수 있습니다. 앱 스토어 없이 설치 — 저장 공간도 거의 차지하지 않습니다.

방법 1 — iPhone (Safari)

1

Safari를 엽니다 (Chrome/Firefox 불가 — iPhone에서는 반드시 Safari 사용).

2

https://apps.amoeba.site/app-car-manager-v2에 접속하여 평소대로 로그인합니다.

3

Safari 하단 툴바에서 '공유' 아이콘 (사각형 + 위쪽 화살표)을 탭합니다.

4

아래로 스크롤하여 "홈 화면에 추가"를 선택 → 오른쪽 상단의 추가를 탭합니다.

5

홈 화면에 Amoeba Car 아이콘이 나타납니다. 탭하면 앱이 전체 화면으로 실행되며 주소 표시줄이 없습니다.

⚠️

iPhone 푸시 알림은 PWA 설치 후에만 작동합니다. 일반 Safari 브라우저로 접속하면 알림을 받을 수 없습니다.

방법 2 — Android (Chrome)

1

Android에서 Chrome을 엽니다.

2

앱 URL에 접속하여 로그인합니다.

3

Chrome이 화면 하단에 "Amoeba Car 설치" 배너를 자동으로 표시합니다. 설치를 탭합니다.

또는 오른쪽 상단 메뉴 (점 3개) → "홈 화면에 추가"를 선택합니다.

4

홈 화면에 아이콘이 나타납니다. 탭하여 앱을 실행합니다.

설치 제거

iPhone: 아이콘을 길게 탭 → 앱 삭제. Android: 아이콘을 길게 탭 → 제거. 앱 내 데이터는 사라지지만 서버 데이터는 그대로 보존됩니다 — 다시 로그인하면 모두 복구됩니다.

비용 기록 방법

1

하단 탐색 바에서 비용 탭을 엽니다. 오른쪽 아래의 둥근 "+" 버튼을 탭합니다.

2

비용 유형을 선택합니다. 8개의 아이콘 칸(라디오 그리드) 중 하나를 탭하며, 한 번에 하나만 선택할 수 있습니다.

3

금액을 입력합니다 (단위: VND, 구분 기호 없이 숫자만 입력하면 시스템이 자동으로 형식을 맞춰 줍니다).

4

지출 날짜를 선택합니다 (기본값은 오늘이며, 최대 7일 전까지 거슬러 선택할 수 있습니다).

5

"차량 선택"을 탭하여 관련 차량(51K-238.91 등)을 선택합니다. 운행 중인 경우에는 해당 운행에 자동으로 연결됩니다.

6

"📷 촬영 / 사진 선택"을 탭하여 영수증 사진을 촬영하거나 갤러리에서 선택합니다. 최대 5장까지 첨부할 수 있으며, 각 사진은 5MB 이하여야 합니다 (PNG/JPG/GIF/WebP).

7

(선택) 추가 설명이 필요한 경우 메모를 입력합니다 (예: "주행 중 연료 소진으로 임시로 20만 원 주유").

8

"기록" 버튼을 탭합니다. 시스템이 사진을 업로드하고 DB에 저장한 뒤, 완료되면 ✓ "기록 완료" 메시지가 표시됩니다.

제출한 비용 다시 보기

비용 탭에는 사용자 본인이 제출한 비용 내역만 표시됩니다 (동료의 비용은 보이지 않습니다). 각 항목에는 다음 정보가 표시됩니다.

  • 유형 + 아이콘
  • 금액 (VND)
  • 날짜 + 연결된 운행 번호 (연결된 경우)
  • 상태 라벨:
    • 승인 대기 — 관리자 승인을 기다리는 중
    • 승인 완료 — 관리자가 승인함
    • 자동 승인 — 자동 승인 기준을 통과함
    • 거절됨 — 탭하여 사유 확인
⚠️

제출 후 7일이 지나면 기록은 자동으로 잠깁니다. 그 이후에는 사용자가 직접 수정할 수 없으며 관리자에게 요청해야 합니다. 처음부터 정확하고 충분한 정보를 입력해 두세요.

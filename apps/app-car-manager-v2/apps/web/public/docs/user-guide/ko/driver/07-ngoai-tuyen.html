네트워크가 약하거나 끊겼을 때

🚧

준비 중인 기능 — 완전 오프라인 모드(네트워크 없이도 운행 조회 및 비용 기록 가능)는 다음 버전에서 제공될 예정입니다. 본 페이지에서는 현재 동작과 향후 계획을 설명합니다.

현재 동작 (오프라인 모드 미지원)

본 앱은 PWA입니다. 네트워크가 끊겨도 앱 자체는 열립니다(홈 화면 아이콘으로 진입 가능). 다만 아래 동작은 실패합니다.

동작네트워크 끊김 상태에서의 결과
홈 화면에서 앱 열기✅ 열림. 셸 화면과 마지막으로 로드된 데이터가 표시
이전에 로드한 데이터 스크롤 조회✅ 수 분간 조회 가능 (브라우저 캐시)
"운행 시작", "운행 종료" 탭❌ "연결 없음" 오류. 신호가 있어야 탭 가능
새 비용 기록 (폼 작성만이라도)❌ 업로드 실패. 폼이 로컬에 저장되지 않음
이전에 로드하지 않은 운행 상세 조회❌ 빈 화면 또는 503 오류

신호가 약할 때의 대처 팁 (현재 버전)

  • 영수증은 휴대폰 카메라로 미리 촬영해 둡니다(앱을 거치지 않고 직접 촬영). 신호가 돌아오면 비용 폼을 열고 갤러리에서 사진을 선택하면 됩니다.
  • 운행 시작/종료 시각을 기억해 둡니다. 신호가 돌아오면 운행 상세 화면에서 버튼을 탭합니다. 시스템은 실제 출발 시각이 아니라 버튼을 탭한 시각을 기록하므로, 필요하면 Notes 필드에 실제 시각을 메모해 둡니다.
  • 장시간 신호가 약한 구간은 피합니다. 약전계 지역(고개, 터널)에 진입하기 전에 미리 버튼을 탭해 두는 것이 좋습니다.

오프라인 모드 계획 (P5 이후)

다음 버전에서는 아래 기능이 지원될 예정입니다.

  • 오늘의 운행 정보 캐싱 — 앱을 열면 즉시 캐시되어 네트워크가 끊겨도 스크롤 조회 가능
  • 오프라인 비용 기록 큐 — 폼이 로컬에 저장되며, 신호가 돌아오면 자동으로 동기화
  • 운행 시작/종료 큐 — 실제 시각을 기록하고 이후 동기화
  • "오프라인 중" 배너를 화면 상단에 표시하여 현재 상태를 알림
📅

출시 예정: 버전 2.1, 2026년 7월경. PWA를 통해 자동 업데이트되므로 별도 작업은 필요하지 않습니다.

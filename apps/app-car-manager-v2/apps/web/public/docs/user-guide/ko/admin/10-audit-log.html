감사 로그 (Audit Log)

앱에서 이 페이지 열기 /audit →

URL
/audit
권한
관리자만 조회 가능
특성
추가 전용 (Append-only) — 수정/삭제 불가. 5년 보관 (/settings에서 설정).

감사 로그는 데이터 변경을 수반하는 모든 작업을 기록합니다: 누가 어떤 운행을 생성/수정/삭제했는지, 누가 사용자 역할을 변경했는지, 누가 시스템 설정을 수정했는지. 문제 발생 시 추적을 위한 유일한 기록입니다.

표시 열 구성

열설명
시각ISO 타임스탬프, Asia/Ho_Chi_Minh 시간대
실행자사용자 아바타 + 이름, 크론 자동 실행 시 "system"
작업이벤트 코드 배지 (TRIP.CREATE, EXPENSE.SUBMITTED, ROLE_SYNC, …)
엔티티대상 유형 (Trip, Vehicle, User, Expense, …)
식별자ID 또는 참조값 (예: TR-1042, 차량 번호판)
IP요청 IP — 비정상 작업 탐지에 활용

작업 유형별 배지 색상

배지 색상은 작업 코드에 포함된 키워드로 결정됩니다:

  • 🟢 Success — ACCEPT 포함
  • 🔵 Accent — ASSIGN 또는 UPDATE 포함
  • 🟣 Info — START 또는 END 포함
  • 🟡 Warning — ALERT 또는 WARN 포함
  • 🔴 Danger — REJECT, CANCEL 또는 DELETE 포함
  • ⚪ Neutral — 그 외 (CREATE, SUBMITTED, OIL_RESET, ROLE_SYNC, PROVISIONED…)

필터

  • 실행자 / 작업 / 대상 참조 검색 — 검색창에 입력
  • 실행자별 필터 — 이벤트를 생성한 적 있는 사용자만 드롭다운에 표시

CSV 내보내기

오른쪽 상단 "CSV 내보내기"를 클릭하면 현재 필터가 적용된 전체 이벤트를 다운로드할 수 있습니다 — Excel/Python 분석에 적합한 형식입니다.

🔒

감사 로그는 앱에서 삭제할 수 없습니다 — raw SQL 권한을 가진 DB 관리자만 (예외적으로) 가능합니다. 이는 규정 준수 필수 기능입니다.

주요 이벤트 코드

코드의미
TRIP.CREATE새 운행 생성
TRIP.UPDATE운행 정보 수정
TRIP.ASSIGN관리자가 기사 및 차량 배정
TRIP.REASSIGN기사 거절 후 관리자 재배정
TRIP.ACCEPT기사 수락
TRIP.REJECT기사 거절 (사유 포함)
TRIP.START기사가 '시작' 버튼 클릭
TRIP.END기사가 '종료' 버튼 클릭
TRIP.CANCEL운행 취소 (관리자 또는 생성자)
EXPENSE.SUBMITTED새 비용 기록 (모든 비용 자동 승인 — 승인 단계 없음)
DRIVER.CREATE / DRIVER.UPDATE기사 프로필 생성 / 수정
VEHICLE.CREATE / VEHICLE.UPDATE / VEHICLE.DELETE차량 생성 / 수정 / 삭제
VEHICLE.OIL_RESET오일 교환 후 주기 초기화
SETTINGS.UPDATE시스템 설정 변경
MAINTENANCE.ACKNOWLEDGED관리자가 정비 알림 처리 확인

ROLE_SYNC로그인 시 역할 자동 동기화 (시스템)

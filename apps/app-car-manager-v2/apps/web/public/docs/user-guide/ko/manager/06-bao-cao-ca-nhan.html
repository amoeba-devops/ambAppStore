목적
월별/분기별 본인 이동 활동 요약
생성 방법
대시보드와 비용 장부에서 데이터를 필터링한 후 CSV 내보내기

현재 매니저 전용 "보고서" 페이지는 별도로 제공되지 않습니다 — 개인 보고서는 기존 페이지에서 데이터를 필터링한 뒤 Excel 파일로 내보내는 방식으로 작성합니다.

방법 1 — 수행한 운행 보고서

1

대시보드 또는 /trips로 이동합니다.

2

필터를 설정합니다.

  • 상태 = "완료"
  • 기간 = 월 초부터 월 말까지

시스템은 매니저 범위에 해당하는 운행만 표시합니다.

3

수동으로 집계하거나(복사하여 정리), 관리자에게 요청하여 Excel로 전체를 내보냅니다 — 관리자는 /reports에서 고급 내보내기 기능을 사용할 수 있습니다 (관리자 전용 접근).

방법 2 — 개인 비용 보고서

1

/costs (비용 장부)로 이동합니다.

2

필터를 설정합니다.

  • 등록자 = 본인 계정 (예: Lê Hoàng)
  • 기간 = 보고 대상 월
3

"CSV 내보내기"를 누릅니다 — 다운로드된 파일은 재무 부서에 그대로 제출할 수 있습니다.

고급 보고서

월별 비용 그래프, 비용이 가장 많이 발생한 노선 TOP, 차량 효율 등 더 복잡한 보고서가 필요한 경우, 관리자에게 /reports 접근을 요청하거나 개발팀에 기능을 제안해 주세요: dev@amoeba.group.

목적
기사가 운행 일지 직접 생성

사용 단계

  1. 고객·경로(출→도) 입력.
  2. 기본 수치 입력(연료/통행료는 완료 시 보완 가능).

  • 관리자가 미리 등록하지 않은 운행에 사용 — 비용/매출 누락 방지.

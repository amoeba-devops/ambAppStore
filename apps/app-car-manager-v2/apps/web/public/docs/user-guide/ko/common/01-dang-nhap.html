방법 1 — Amoeba 싱글 사인온 (권장)

일반 사용자를 위한 표준 방식입니다. ama.amoeba.site에 한 번 로그인하면 비밀번호 재입력 없이 앱에 접근할 수 있습니다.

1

브라우저에서 https://ama.amoeba.site를 열고 Amoeba 이메일·비밀번호로 로그인합니다.

2

Amoeba 홈에서 "내 앱" 영역의 Car Manager 아이콘을 클릭합니다.

3

시스템이 역할에 맞는 홈 화면으로 자동 이동시킵니다:

  • 관리자 / 매니저 → 대시보드
  • 기사 → 오늘 화면
ℹ️

세션 유효 시간은 8시간입니다. 이후에는 자동 로그아웃되며 Amoeba에서 다시 로그인해야 합니다.

방법 2 — 직접 로그인 페이지

Amoeba 세션 없이 앱 URL에 직접 접근하면 앱 자체 로그인 화면이 표시됩니다:

1

회사 코드(대문자, 관리자로부터 받음)를 입력합니다.

2

Amoeba에 등록된 전화번호를 국제 형식으로 입력합니다 (+84 90 123 4567).

3

로그인을 클릭. 시스템이 인증 후 역할별 홈으로 이동시킵니다.

⚠️

회사 코드나 전화번호가 기억나지 않으면 개발팀이 아닌 회사 관리자에게 확인하세요.

최초 온보딩 — 관리자로부터 정보 받는 절차

처음 시스템을 사용하는 경우, 회사 관리자가 SMS / 카카오톡 / 텔레그램 / 이메일을 통해 2가지 필수 정보를 보내드립니다:

정보예시주의
회사 코드 (ent_code) VN01, AMOEBA-VN 관리자가 제공. 대문자, 공백 없음.
본인 전화번호 +84 90 555 8819 회사 등록 시 Amoeba에 입력한 번호. AMA 시스템과 정확히 일치해야 함.

관리자가 보내드릴 메시지 템플릿

2. 회사 코드: VN01
3. 전화번호: 본인 전화번호 (Amoeba 등록 번호)
4. "로그인" 클릭

로그인 후 역할에 따라 자동으로 권한이 부여됩니다.

지원 문의: [관리자 이름 / 전화번호]

로그인 성공 후

  • 시스템이 DB에 본인 사용자 레코드를 자동 생성
  • Amoeba 권한에 따라 역할 자동 부여 (관리자 / 매니저 / 기사)
  • 기사의 경우: 관리자가 운전면허, 등급, 만료일을 별도 등록 — 본인이 할 일 없음

💬

관리자 참고사항: 직원이 Amoeba 계정을 받지 못한 경우, 인사팀에 연락해 먼저 전화번호 + 역할을 AMA에 등록한 후 로그인 정보를 발송하세요. 앱에 입력하는 전화번호는 AMA에 등록된 번호와 일치해야 합니다.

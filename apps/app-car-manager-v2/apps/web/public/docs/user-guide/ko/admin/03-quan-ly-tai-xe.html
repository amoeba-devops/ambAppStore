기사 관리 (Drivers)

앱에서 이 페이지 열기 /drivers →

URL
/drivers (목록) · /drivers/new (추가) · /drivers/[id]/edit (수정)
운전면허증
만료일이 임박하면 시스템이 자동으로 알림 발송 (≤ 30일 = 빨간색, ≤ 90일 = 노란색)

기사 목록

각 기사 행에 표시되는 정보:

  • 아바타 + 이름 + 이메일
  • 전화번호 (모바일에서 클릭 시 전화 연결)
  • 면허 번호 + 면허 종류 (B2, C, D 등)
  • 상태 (사용 가능 / 운행 중 / 휴무 / 사용 불가)
  • 운전면허 만료일 — ≤ 30일이면 빨간색 표시

새 기사 추가

1

기사를 추가하려면 먼저 해당 사용자 계정이 있어야 합니다. 아직 없다면 새 사용자 초대 에서 MEMBER (DRIVER) 역할로 추가하세요.

2

/drivers/new로 이동 → 드롭다운에서 사용자 선택 (기사 프로필이 없는 사용자만 표시)

3

운전면허 정보 입력:

  • 면허 번호 (예: B2-1234567)
  • 면허 종류 — A2 / B1 / B2 / C / D / E / F
  • 만료일
  • 전화번호 — +84 90 555 8819 형식
  • 비상 연락처 (선택 사항)
4

"저장" 클릭. 기사는 이제 운행에 배정할 수 있습니다.

운전면허 만료 임박 시 갱신

기사가 면허를 갱신한 경우, /drivers/[id]/edit으로 이동 → 새 만료일을 업데이트하세요. 시스템의 알림이 초기화됩니다.

📅

시스템은 운전면허 만료 30일 전에 알림을 발송합니다. 면허가 만료된 기사도 "대기 중" 상태로 유지되지만, 운행에 배정하지 않도록 관리자가 직접 확인해야 합니다.

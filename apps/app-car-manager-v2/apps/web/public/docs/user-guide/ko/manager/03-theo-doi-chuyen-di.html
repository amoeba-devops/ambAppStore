내 운행 목록

/trips 페이지는 사용자의 전체 운행을 출발 시각 최신순으로 표시합니다. 각 항목에는 다음이 포함됩니다:

  • 운행 코드 (TR-3001…)
  • 구간 (출발지 → 도착지)
  • 출발 날짜 + 시각
  • 차량 + 기사 (배정된 경우)
  • 상태 레이블 (배정 대기 / 기사 확인 대기 / 확정 / 운행 중 / 완료 / 취소)

상단 필터를 사용하여 다음 기준으로 검색할 수 있습니다:

  • 상태 (복수 선택 가능)
  • 날짜 범위
  • 차량 / 기사
  • 키워드 (주소 또는 목적으로 검색)

운행 상세

상세 페이지에서 확인할 수 있는 내용:

  • 경로 지도 (Google 임베드)
  • 기본 정보 — 출발지, 도착지, 시각, 목적, 메모
  • 경유지 (있는 경우)
  • 인원 + 차량 — 승객, 기사, 차량, 번호판
  • 상태 이력 — 각 단계 처리자 이력 (생성·배정·확인·시작·종료한 사람)
  • 하단 액션 버튼 (아래 참조)

특별 케이스: 승객으로 탑승하는 운행

다른 관리자/매니저가 사용자를 위해 운행을 신청한 경우 (TR-3002), 해당 운행도 목록에 표시됩니다. 단, 취소 권한은 없습니다 — 운행 생성자 또는 관리자만 취소할 수 있습니다.

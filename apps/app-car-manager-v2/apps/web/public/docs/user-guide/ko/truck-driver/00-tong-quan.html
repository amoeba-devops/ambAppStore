트럭 기사 화면은 운행 완료에 초점 — 승용차 같은 수락/거절이 없습니다. 완료할 운행을 보고, 종료 시 수치를 기록하며, 완료 운행을 다시 봅니다.

3개 페이지

  1. 오늘 — 완료할 운행 + 차량 + 완료됨.
  2. 운행 완료 — 연료·통행료·주행거리 입력.
  3. 새 운행 기록 — 운행 일지 직접 생성.

승용차와 차이

  • 운행 수락/거절 단계 없음.
  • 배차가 아니라 수치 기록·비용 확정에 집중.

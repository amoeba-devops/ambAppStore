기간
우측 상단 선택 (기본 이번 달)

사용 단계

  1. 우측 상단에서 기간 선택(이번 달 / 다른 달).
  2. 전체 · HCM · 동나이 · Baiksan 버튼으로 지역 필터 — 전체 수치가 함께 변경.
  3. 4개 지표 확인: 매출 · 총비용 · 순이익 · 운행 수 (전기 대비 ▲/▼).
  4. 월별 매출·이익 차트와 비용 구성 도넛 확인.
  5. 아래로 스크롤해 지역별 표와 최근 운행 확인 — 운행 클릭 시 상세 열림.
  6. 우측 운행 생성 버튼으로 새 일지 작성.

계산 로직

  • 순이익 = 매출 − 총비용(연료 + 통행료 + 기타 + 고정비).
  • 선택한 기간·지역의 완료된 운행만 집계.
  • 전기 대비 % = 같은 지역 직전 달 대비.
  • 운행별 연료비 = 리터 × 단가(지역 마감 시 정해진 정액 적용).

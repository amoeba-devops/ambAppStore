용어집

시스템에서 자주 등장하는 용어 목록 (가나다순).

A — H

AMAAmoeba Management — Amoeba의 계정·조직 관리 플랫폼. 생태계 모든 앱에 SSO 제공.
감사 로그Audit log — 모든 데이터 변경을 기록, 수정/삭제 불가, 5년 보관.
자동 승인Auto-approve — 설정된 임계값 이하의 비용을 관리자 개입 없이 자동 승인.
정비정기 점검 — 오일 교환, 브레이크·타이어 점검 등. 주행거리와 기간 기준 자동 알림.
BFFBackend-For-Frontend — 프론트엔드 전용 서버, 프록시 + 비즈니스 로직 처리.
운행 (Trip)차량 1회 사용 — 출발지, 도착지, 시각 포함. 핵심 데이터 엔티티.
경유지 (Stopover)출발지와 도착지 사이의 중간 정류지점.
조직 (Entity)앱을 사용하는 회사/조직 — 각 조직 데이터는 완전 격리 (멀티 테넌시).

I — Q

7일 잠금비용 제출 후 7일 경과 시 본인 수정 불가 — 관리자만 수정 가능.
Maintenance Alert정비 알림 — 오일/정기검사 만료 임박 시 자동 알림.
멀티 테넌시인프라는 공유하되 데이터는 격리하는 방식 — 조직 A는 조직 B 데이터를 볼 수 없음.
주행거리계 (Odometer)차량 누적 주행거리, 계기판 표시 — 정비 주기 계산에 사용.
PWAProgressive Web App — 모바일 홈 화면에 앱처럼 설치 가능한 웹 앱.

R — Z

SSOSingle Sign-On — AMA에 한 번 로그인하면 모든 앱 사용 가능.
상태 머신 (State machine)생명주기 관리 모델 — 운행이 정해진 순서로 7개 상태를 거침.
소프트 삭제 (Soft delete)DB에는 남기고 삭제 처리 — 복구 가능. 앱에는 하드 삭제 없음.
소프트 경고 (Soft-warning)조작은 막지 않고 경고만 표시 — 관리자는 충돌이 있어도 계속 진행 가능.
역할 (Role)관리자 / 매니저 / 기사 — 보이는 페이지와 가능한 작업을 결정.
Web Push브라우저 푸시 알림 — 앱이 닫혀있어도 팝업 표시.

## 1. Feature A — Q&A 검색 (SCR-001)

### TC-A01 — 자연어 입력 및 검색 개시 (FR-001 / R-01) · P0
- **전제**: Q&A 화면 진입, 코퍼스 적재됨
- **입력**: "자동차 엔진용 고무 오일씰, 재질은 NBR 고무입니다" (ko)
- **절차**: 입력 → 전송
- **기대결과**: 검색 개시, **타이핑 인디케이터 300ms 이내** 표시, 후보 검색 요청(POST `/api/v1/qa/search`) 발생
- **판정 기준**: 빈/2자 미만 입력은 거부(에러 메시지)

### TC-A02 — 빈/짧은 입력 거부 (FR-001) · P0
- **입력**: 공백, "a"(1자)
- **기대결과**: 검색 미개시, 입력 검증 에러. 외부/DB 호출 없음

### TC-A03 — 의미검색 후보 순위 제시 (FR-002 / R-01) · P0
- **입력**: 유효 제품 설명
- **기대결과**: 후보 N=5 이내 카드가 **신뢰도 내림차순**으로 표시. 각 카드 HS코드·품명·신뢰도% 노출
- **판정**: 최소 유사도 floor 미만 행은 제외

### TC-A04 — 교차언어 매칭 (FR-002 / NFR-005) · P0
- **입력**: 동일 제품을 ko / en / vi 각각 입력 ("NBR oil seal" / "Phớt cao su NBR")
- **기대결과**: 베트남어 코퍼스(`Tên hàng`) 기반 동일 HS6(4016.93) 후보가 3개 언어 모두에서 상위 노출

### TC-A05 — 모호 시 순차 명확화 질문 (FR-003 / R-02 / POL-001) · P0
- **전제**: top1−top2 score gap < 0.08
- **기대결과**: **1회 1질문**(가공상태/재질/용도 등)만 제시, 칩 선택 가능
- **판정**: 답변 시 후보 재랭크가 **측정 가능하게** 변함

### TC-A06 — 명확화 최대 라운드 종료 (FR-003 / POL-001) · P1
- **절차**: 모호 입력으로 5라운드 연속 진행
- **기대결과**: **5라운드 초과 시 질문 중단**, 현재 최선 후보 제시(`needQuestion=false`)

### TC-A07 — 후보 카드 필드 완전성 (FR-004 / R-03) · P0
- **기대결과**: 각 후보에 HS코드·품명·원산지·단위·신뢰도 밴드(hi/mid/lo 색상) **모두** 렌더

### TC-A08 — 확정 및 이력 저장 (FR-005 / R-03) · P1
- **절차**: "이 코드로 확정" 클릭
- **기대결과**: `hsm_query_logs` 1행 저장(입력·선택 HS·신뢰도·session·timestamp), `hsm_resolution_audits` 기록. 이력 재조회 가능

### TC-A09 — 근거 출처 표시 (FR-006 / R-03) · P1
- **기대결과**: 각 후보가 **≥1개 참조 행**(회사/파일/건수) 출처 링크 노출. 클릭 시 SCR-004 이동
- **판정**: RAG 회수 컨텍스트와 표시 출처 일치

### TC-A10 — 후보 0건 폴백 (PRC-002) · P2
- **입력**: 코퍼스에 없는 설명
- **기대결과**: "확신 가능한 후보 없음 → 속성 폼 시도" CTA 노출

## 2. Feature B — 바코드 GTIN 조회 (SCR-002)

### TC-B01 — GTIN 14자리 정규화 (FR-010 / R-04) · P0
- **입력**: GTIN-8/12/13/14 각각 (예: `8806311`, `08806311234567`)
- **기대결과**: 모두 **14자리로 left-pad 정규화** (`padStart(14,'0')`)

### TC-B02 — 체크디지트 검증 통과 (FR-011 / R-04) · P0
- **입력**: 알려진 정상 GTIN
- **기대결과**: modulo-10 검증 통과 → 조회 진행

### TC-B03 — 체크디지트 검증 실패 (FR-011) · P0
- **입력**: 마지막 자리 변조 GTIN
- **기대결과**: **필드 에러, 조회/외부호출 0건**(`InvalidGtinError`)

### TC-B04 — 도착국 미선택 차단 (FR-012 / R-05) · P0
- **절차**: 국가 미선택 후 Resolve
- **기대결과**: 조회 차단, 국가 선택 요구 메시지

### TC-B05 — L1 직접 매핑 적중 (FR-013 / R-05) · P0(MVP)
- **전제**: `hsm_gtin_hs_maps`에 매핑 존재
- **기대결과**: HS6 즉시 반환, **외부 API 호출 0건**, source 표시

### TC-B06 — 국가 HS 확장 (FR-017 / R-06 / FR-043) · P0(MVP)
- **입력**: 해석된 HS6 + 도착국(VN)
- **기대결과**: `hsm_hs_country_extensions`에서 **8~10자리 full code + 관세율** 반환. 확장행 없으면 HS6만 + "국가자릿수 없음" 플래그

### TC-B07 — 법적 고지 노출 (FR-022 / R-08 / POL-002) · P0
- **기대결과**: 모든 바코드 결과에 "추천값·확정책임 화주" 고지 **상시 노출**

### TC-B08 — [후속] L2~L4 폴백 파이프라인 (FR-014~016) · P1
- **전제**: GS1/Claude 연동 활성
- **기대결과**: L1 miss → 제품정보(GPC) → GPC→HS(1:다 ranked) → AI 분류(confidence). 단계별 상태 PipelineLayers 표시

### TC-B09 — [후속] 저신뢰 검토 큐 라우팅 (FR-019 / FR-016) · P1
- **전제**: L4 confidence < 0.70(review_threshold)
- **기대결과**: 자동 반환 안 함, `hsm_review_queues` status=PENDING 등록

### TC-B10 — [후속] 학습 매핑 write-back (FR-018 / R-07) · P1
- **절차**: L2~L4로 해석된 GTIN 재조회
- **기대결과**: 재조회가 **L1에서 적중**(source=learned). audit 기록(FR-020)

## 3. Feature C — 속성/엑셀 (SCR-003)

### TC-C01 — 속성 폼 단건 분류 (FR-030/033 / R-09) · P0
- **입력**: 품명·재질·용도·원산지·단위·가공상태
- **기대결과**: Feature A 엔진 재사용 → HS 후보 + 신뢰도 반환

### TC-C02 — 엑셀 템플릿 업로드 수용 (FR-031 / R-10) · P0
- **입력**: 고정 양식 준수 `.xlsx`
- **기대결과**: 파일 수용, 처리 개시. 정의되지 않은 컬럼/초과 크기는 거부

### TC-C03 — 양식 검증 행별 오류 리포트 (FR-032 / R-10) · P0
- **입력**: 12행 품명 누락, 27행 단위 "EA" 미정의, 88행 HS 형식 오류
- **기대결과**: **행·컬럼·사유** 정밀 오류 리스트 출력 (`{row,col,reason}`)

### TC-C04 — 행별 분류 (FR-033 / R-09) · P0
- **기대결과**: 각 유효행에 HS코드 + 신뢰도 부여

### TC-C05 — 비동기 배치 처리 (FR-033 / NFR-004 / C-6) · P0
- **입력**: 임계 초과 대용량(예: 1,000행)
- **기대결과**: BullMQ 큐 적재, 진행률(`GET /excel/jobs/:id`) 폴링, 행 타임아웃은 `error` 표시 후 계속

### TC-C06 — 저신뢰 행 플래그 (FR-036 / R-11 / POL-001) · P2
- **기대결과**: confidence < 0.70 행 **⚑수동검토** 자동 플래그

### TC-C07 — 결과 엑셀 다운로드 (FR-034 / R-10) · P1
- **기대결과**: 입력행 보존 + HS/신뢰도/근거 컬럼 추가된 워크북 다운로드

### TC-C08 — 빈 템플릿 다운로드 (FR-035 / R-11) · P1
- **기대결과**: 필수 입력 스키마와 일치하는 빈 템플릿 제공

### TC-C09 — 폼 초기화 (UI) · P2
- **기대결과**: 초기화 시 모든 필드 리셋

### TC-C10 — 정규화 결과 객체 일치 (FR-041) · P0
- **기대결과**: 반환 객체 = `{hs_code, hs6, description, confidence, source, country?}` (3모드 공통)

## 4. 결과 상세 (SCR-004)

### TC-D01 — 3모드 공통 결과 상세 렌더 (FR-041 / R-12) · P0
- **절차**: Q&A·바코드·엑셀 각 결과에서 상세 진입
- **기대결과**: HS_full+HS6+국가, 품명·원산지·단위, 신뢰도 밴드 동일 레이아웃 렌더

### TC-D02 — 근거 출처/설명가능성 (FR-006 / R-12) · P0
- **기대결과**: 참조 행 인용(회사·파일·건수) + 해석 출처(direct/gpc/api/manual/learned) 표시

### TC-D03 — 해석 메타/감사 연계 (FR-020 / R-12) · P0
- **기대결과**: 검증자·기록시각·로그 ID(`hsm_query_logs #`/`hsm_resolution_audits`) 표시

### TC-D04 — 관세/부가세 연계 (FR-042) · P2
- **기대결과**: 참조 데이터에 세율 존재 시 관세율(XNK)·부가세(VAT) 표시

## 5. 참조(Reference) — RAG (SCR-005)

### TC-R01 — 다형식 import: 표준 (FR-040 / R-13) · P0
- **입력**: `BaoCaoHangChiTiet` 형식 파일
- **기대결과**: 자동 감지 → 정규화 → `hsm_hs_references` 적재, `hsm_import_batches`에 총/성공/실패 요약

### TC-R02 — 다형식 import: 변형/커스텀 (FR-040) · P0
- **입력**: `BaoCaoToKhai`(변형), `VMSG`(커스텀)
- **기대결과**: 해당 어댑터로 부분 적재. 미지원 형식은 **⚑어댑터 필요** 상태로 graceful 처리(전체 실패 아님)

### TC-R03 — 중복 제거 (FR-044 / R-13) · P1
- **입력**: 회사 간 동일 (HS+품명+원산지+단위) 행
- **기대결과**: 중복 스킵, dedup 카운트 집계

### TC-R04 — 임베딩 생성 → RAG 적재 (FN-041 / R-13) · P0
- **기대결과**: 신규 행 임베딩 생성 후 pgvector upsert. 이후 Feature A/C 검색에서 회수됨(TC-A03 연계)

### TC-R05 — 8/10자리 HS 지원 (FR-043 / R-06) · P0
- **입력**: 8자리·10자리 베트남 HS 혼재 코퍼스
- **기대결과**: HS6 기준 매칭 + 국가확장으로 8~10자리 관리, 형식 오류 없음

### TC-R06 — 검토 큐 승인 → learned 저장 (FR-019/018 / R-14) · P1
- **절차**: 큐 항목 승인
- **기대결과**: `hsm_gtin_hs_maps`에 **source=manual** 저장, audit 기록. 이후 L1 적중

### TC-R07 — 검토 큐 할당 (R-14) · P2
- **기대결과**: 항목 담당자 할당, status 갱신

### TC-R08 — 매핑 편집 + 국가확장 미리보기 (FR-043 / R-14 / POL-005) · P1
- **절차**: GTIN/GPC/country-ext 편집 후 저장(검증)
- **기대결과**: 검증 통과 시 저장(source=manual), VN/KR/US 전체코드+관세 미리보기 갱신. **관리자 역할만 가능**

## 6. 어드민(설정) — (SCR-006)

### TC-S01 — 설정 화면 역할 제한 (R-18 / POL-005) · P0
- **절차**: 일반 사용자 토큰으로 `/app-hscode/admin` 접근
- **기대결과**: **403/접근 거부**. 관리자 역할만 진입

### TC-S02 — AI 연결 설정 저장 (R-18) · P1
- **입력**: Claude API Key·모델(claude-sonnet-4-6)·일일 예산(50)
- **기대결과**: `hsm_app_settings` upsert. **API 키는 암호화 저장, 평문 미표시(마스킹)**

### TC-S03 — 설정 변경 audit (R-18 / POL-003) · P1
- **기대결과**: 설정 변경마다 변경자·시각 audit 기록

### TC-S04 — 연결 테스트 (R-18) · P2
- **절차**: "연결 테스트" 클릭
- **기대결과**: Claude/어댑터 ping 결과(성공/실패) 표시. 실패해도 앱 중단 없음

### TC-S05 — 외부 API/어댑터 토글 (R-18 / POL-004) · P1
- **기대결과**: GS1/VN-bieu-thue/KR-customs 토글·엔드포인트·캐시 TTL 저장 → 런타임 반영(DB 설정이 .env 오버라이드)

### TC-S06 — 임베딩 공급자/차원 변경 경고 (R-18 / C-2) · P1
- **절차**: 차원(N) 변경 저장
- **기대결과**: "pgvector 인덱스 재생성 + 전체 재임베딩 필요" 경고. 재임베딩 트리거 동작

### TC-S07 — 임계치 변경 즉시 반영 (R-18 / POL-001) · P1
- **입력**: gap/review/flag/최대라운드 변경
- **기대결과**: Q&A 명확화(FR-003)·AI 분류(FR-016)·엑셀 플래그(FR-036)에 즉시 반영

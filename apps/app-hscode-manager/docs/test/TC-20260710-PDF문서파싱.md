## 1. PDF 추출 (TC-P)
- TC-P01(P0/R5): 키 미설정 상태 PDF 업로드 → 400 + "PDF 분석은 AI 설정 필요" 안내(무크래시).
- TC-P02(P0/R1·R2): 키 설정 상태 텍스트 PDF(품명·성분 표) 업로드 → 품목 추출 → 요청건 생성(PROCESSING).
- TC-P03(P0/R3): 스캔본(이미지) PDF → 비전으로 품목 추출(핵심 필드).
- TC-P04(P0/R2): 추출 품목이 기존 비동기 매칭 파이프라인으로 처리(워커 매칭→READY).
- TC-P05(P0/R4): 품명 미검출/모호 행 → needsReview 유지(폐기 없음).
- TC-P06(P1/R6): 대용량/다페이지 PDF → 상한 내 처리, 초과 시 명확한 400/note.
- TC-P07(P1): 손상/비PDF를 .pdf로 위장 업로드 → 400(무크래시).

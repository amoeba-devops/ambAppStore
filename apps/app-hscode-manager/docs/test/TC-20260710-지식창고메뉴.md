## 1. 테스트 환경 / 사전조건

| 항목 | 값 |
|------|-----|
| DB | 스테이징 PostgreSQL 15 + pgvector, `hsm_kb_*` 마이그레이션 적용 완료 |
| 인증 | AMA JWT — USER/ADMIN/SADMIN 3종 토큰 확보 |
| 데이터 | 카테고리 3종(주요국 HS 기준표/HS 상식/통관 기초), 게시글 ≥5, 태그 몇 종 시딩 |
| 첨부 | 로컬 볼륨(`ATTACHMENT_DIR`) 마운트, 다운로드 검증용 파일 |
| AI | admin-settings에 Claude 연결 설정(번역 TC용) |
| 공통 응답 | `{ success, data, error?, timestamp }`, 에러코드 `HSC-E****` |
